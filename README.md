# HailSum Calculator

Welcome to the HailSum Calculator! This program offers a variety of mathematical tools, including basic arithmetic, trigonometric functions, and exponentiation and roots.

# Features

Four Basic Functions: Addition, Subtraction, Multiplication, Division, and Modulus.
Trigonometric Functions: Calculate sine, cosine, and tangent values.
Exponents & Roots: Calculate powers and n-th roots.

# Getting Started

To use the calculator:

Compile and run the program.
You will be presented with a menu of tools:
1: Four Basic Functions (+, -, *, /)
2: Trigonometric Functions (sin, cos, tan)
3: Exponents & Roots
Enter the tool number to select the desired functionality.

# Example Usage
Basic Functions:
Input two numbers and an operator to perform operations like addition or subtraction.

Trigonometric Functions:
Input a trigonometric function (sin, cos, tan) and a value in radians.

Exponents & Roots:
Choose between calculating an exponent or a root by entering the base and exponent/root.
